## Step 3 — Upload the PDF

On the OnlineHashCrack website:

1. Click **Browse / Choose File**.
2. Select:

```text
My-Locked-PDF1.pdf
```

3. Click **Upload**.

The website will process the PDF and display its hash.

---

## Step 4 — Copy the Hash

Copy the complete hash generated by OnlineHashCrack.

The hash should have the PDF hash format beginning with:

```text
$pdf$
```

If the extracted value contains additional characters such as:

```text
b'
```

remove those characters before saving the hash.

---

## Step 5 — Create `hash1.txt`

Open **Notepad**.

Paste the extracted hash into the file.

Save it as:

```text

```
