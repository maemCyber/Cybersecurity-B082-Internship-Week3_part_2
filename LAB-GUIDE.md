# LAB GUIDE — PASSWORD CRACKING PART 2

## Hash Calculator → Password Cracker

This practical follows a simple two-tool workflow.

### 1. Protected PDF
Start with the authorized protected PDF supplied for the lab.

### 2. Hash Calculator
Upload the PDF and obtain its hash.

### 3. Hash
Copy the complete generated hash without modification.

### 4. Password Cracker
Paste the hash into the Password Cracker and start the authorized lab process.

### 5. Verification
Use the recovered password to verify that the protected PDF opens.

## Important

Do not use this workflow against files, accounts, or systems without authorization.
